# Semântica de cobertura

Zero notificações em uma publicação válida é diferente de ausência de
publicação. `coverage.status` distingue `AVAILABLE`, `PARTIAL` e `UNAVAILABLE`.
O território consultado é o da notificação/unidade quando publicado; não há
fallback silencioso para residência do paciente. Totais são agregados no
PostgreSQL sobre `cases_total`, respeitando o grão da fato.
